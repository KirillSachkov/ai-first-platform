# Project skills

The skill directories in this folder come from [mattpocock/skills](https://github.com/mattpocock/skills), release `v1.3.1`. They are the 27 skills listed in that release's Claude plugin manifest. The upstream MIT license is in `LICENSE.mattpocock`.

Codex and OpenCode can discover project skills here. `.claude/skills` points to this folder for Claude Code. Keep one copy of each skill here when updating the set.

The upstream `setup-matt-pocock-skills` skill configures the issue tracker, triage labels, and domain documentation layout for this project; run it once those choices are ready.

Project adaptations: references to the project glossary use `DOMAIN.md` rather than upstream `GLOSSARY.md`. The setup templates remain upstream originals; see `docs/agents/` for the active project configuration.
