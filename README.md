# AI-first Platform

Платформа для совместной работы сотрудников и агентов: проекты, репозитории, инструкции и доступы компании в одном месте.

## Первая версия

- Учётные записи сотрудников и вход по приглашению.
- Проекты, объединяющие репозитории GitHub и инструкции.
- Доступ сотрудника и его агента к разрешённым проектам.
- Подготовка рабочего окружения агентом по инструкциям проекта.
- Отзыв доступа сотрудника к платформе и репозиториям при увольнении.
- Модуль интеграций с GitHub в качестве первой интеграции.

Исходные требования: [customer-requirements.md](customer-requirements.md).

## Состояние проекта

Репозиторий подготовлен для начала разработки. Стек, архитектура и способ подключения агента пока не выбраны. Код приложения, сборка, тесты и CI будут добавлены вместе с реализацией.

## Начало работы

```sh
git clone git@github.com:KirillSachkov/ai-first-platform.git
cd ai-first-platform
```

Перед реализацией изучите требования и согласуйте технический стек и границы первой версии. После выбора стека добавьте сюда команды установки зависимостей, локального запуска и проверок.

## Работа с репозиторием

- Основная ветка — `main`. Для изменений создавайте отдельные ветки и pull requests.
- Фиксируйте lock-файлы выбранного менеджера зависимостей в Git.
- Храните секреты в локальных `.env`-файлах; документируйте нужные переменные в `.env.example` без реальных значений.
- Добавляйте инструкции запуска и проверки одновременно с соответствующим кодом.
